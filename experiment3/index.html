Experiment 3 - Alternate Worlds

Description

This project uses generative design and tiles to make a landscape. The goal of this project is to learn how to separate offline generation of a datastructure from online rendering. Additionally, the goal is to use autotiling to have smooth transition tiles.

Technical

The main thing that makes the transition tiles look so smooth for the walls of the dungeon / edge of the lake are creating adjacency rules. For example, if the tile to the right and underneath the lake is a grass tile, but the tile above it is a water tile, then it is an edge tile. This means that the selected tile has to be a corner tile, specifically the bottom right corner. In simple terms, the steps taken to generate my landscapes are generating a grid with lakes, that are marked by '.'. I use a helper function to ensure the rooms don't generate on top of each other. Then, the grid is drawn and filled with tiles which follow the rules in the handleWalls() function.

Reflection

Setting up the rules took a bit of figuring out, and then I remembered I had done a similar project before. I was able to look back on it and understand how the rules for that generator worked. Even though I ended up working out how to work the transition tiles, I did fail in a few ways. Specifically, I really wanted to add chests that open and close in my dungeon generator. Although I put in a good amount of time trying to get it to work, I ended up giving up and opting to just have static chests as decoration.
