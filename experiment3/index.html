Experiment 3 - Alternate Worlds

Description

This project uses generative design and tiles to make a landscape. The goal of this project is to learn how to separate offline generation of a datastructure from online rendering. Additionally, the goal is to use autotiling to have smooth transition tiles.

Technical

The main aspect that makes the transition tiles look so smooth for the walls of the dungeon/ edge of the lake are creating adjacency rules. For example, if the tile to the right and underneath the lake is a grass tile, but the tile above it is a water tile, then it is an edge tile. This means that the selected tile has to be a corner tile, specifically the bottom right corner. In simple terms, the steps taken to generate my landscapes are generating a grid with lakes, that are marked by '.'. I use a helper function to ensure the rooms don't generate on top of each other. Then, the grid is drawn and filled with tiles which follow the rules in the handleWalls() function.

Reflection

Throughout this project, I struggled with various issues, such as setting up tile adjacency rules, creating rooms and lakes that do not overlap, and tile animations. I enjoyed playing with different aspects of the worlds to make them feel less static. The real challenge, though, was adding both of these projects so that they could be displayed on the same page simultaneously. I had to turn the projects, which were originally designed on Glitch, into instance mode. Overall, I'm proud of how this project turned out. It may look simple, but it took a good amount of time and effort, and I'm proud of my work.
