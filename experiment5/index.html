Description

In this project, we're making a generator that looks at inspiring images, creates its own versions based on them, and keeps tweaking its designs to get better scores over time.

Technical

In this project, I let the user choose an inspiring image from a dropdown, and the generator adjusts its behavior based on that choice. It creates designs that loosely resemble the image, especially if you slowly lower the mutation rate over time. I made sure the mutation rate slider actually changes how much the design evolves, so you can control how fast or subtle the changes are.
